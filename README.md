
# Banking Data Engineering Platform

## Project Overview
An end-to-end banking data engineering platform built using
Google Cloud Platform.

## Architecture
- Google Cloud Storage – Raw data landing
- Python – Data generation and transformation
- Apache Beam – Batch and streaming processing
- Dataflow – Managed pipeline execution
- Pub/Sub – Real-time event ingestion
- BigQuery – Data warehouse
- Cloud Run – Containerized Python applications
- Cloud Composer – Workflow orchestration
- Cloud Scheduler – Scheduled execution
- Cloud Logging and Monitoring – Observability

## Pipeline Types
1. Batch Data Pipeline
2. Real-time Streaming Pipeline

## Technology Stack
- Python 3.12
- Google Cloud Platform
- Apache Beam
- SQL
- Docker
- Git and GitHub

## Data Domains
- Customers
- Accounts
- Transactions
